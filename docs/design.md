# 产品设计

## 定位

Bobby Carrot 5 Web 是第五代的现代浏览器重制：保留原始关卡、高清美术、MIDI 和谜题机制，移除 Java ME 时代的小屏幕、数字键与下载包操作限制。

## 保留

- 原始关卡布局、terrain/object byte ID；
- UP9 高清版像素美术和原动画素材；
- 经字节码/原版行为确认的机关规则；
- 原始 MIDI 编曲；
- Base / UP1~UP9、章节名、历史 A~F 难度资料等发行 metadata。

## 现代化

- 响应式大视野 Camera；
- 桌面键盘与手机 Swipe / Pinch；
- 继续游玩、随机一关；
- 本地完成进度、Bonus Coin / Golden Carrot 档案；
- Engine Debug / Tile Inspector；
- 可替换 AudioBackend。

## 选关结构

不把 485 关平铺，也不把内部 canonical `001...485` 暴露给玩家。

玩家视角保持原作结构：

```text
Base / UP1 ... UP9
  ↓
原始章节
  ↓
章节内关卡
```

公开 ID：

```text
base-0-1
base-1-1
up1-2-7
up9-4-12
```

内部 `001...485` 只负责内容去重和旧存档兼容。以后自定义地图可以使用独立的 `custom-*` 命名空间。

## 难度

历史“简单 A/B/C、中等 D/E、困难 F”并不是新关卡，而是从正式 485 关中重新编排的合集。

- 288 个非教学关能直接获得历史难度标签；
- 192 个正式关没有历史 A~F 标签；
- 对这 192 关，构建工具用已标注关卡的地图尺寸、对象密度、特殊机关种类、动态实体等特征做 KNN 估算；
- 估算结果在 UI 中必须带 `≈`，不能伪装成官方难度。

## 明确不做

- 在网页里运行 Java ME 模拟器；
- 强制 320×240 视野；
- 模拟数字键/软键 UI；
- 把全部 485 关平铺成一个巨大列表；
- 把原游戏重画成另一套视觉风格。
