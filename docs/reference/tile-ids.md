这里只记录已经通过 UP9 高清版字节码、资源或帮助文本确认的事实。视觉猜测必须明确标注“推断”，不允许把猜测写成已确认规则。

## 藤蔓的命名修正

早期工程把 `0xEE` 暂称为 `BEANSTALK_TOP`，后续追踪原版 `S()` 后确认它实际位于豆田基座。源码现在使用 `BEANSTALK_BASE`，旧名字只保留为兼容别名。

更详细的动态动画和藤蔓/荷叶运行时行为见 `runtime-animation.md`。
