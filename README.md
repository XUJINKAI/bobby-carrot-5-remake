# Bobby Carrot 5 Remake

**兔子波比5** 的现代 Web 全新重制项目。

本项目使用完全重写的游戏引擎，在保留原版关卡原汁原味的基础上，额外新增了地图编辑器以及地图分享功能，也预留了接口用于扩展新的地图机制。

在线游玩：<https://bc5r.xujinkai.net>

## 特性

- **Adventure 冒险模式**：按原版 Forever + 9个UP包结构游玩全部 40 章 400 个关卡，包含章内进度、存档、奖励关、商店等原版冒险系统。
- **Explore 自由探索模式**：自由浏览原版 400 个普通关卡和 80 个 Bonus 奖励关，支持关卡过滤、调试模式、地图编辑和自由缩放。
- **Editor 地图编辑器**：自由组合地图元素，创造你自己的关卡，并分享出去。
- **现代引擎重制**: 完全重写的现代引擎，而非简单翻译原版代码，支持完整的Debug/Inspector功能供分析学习。
- **录制功能**: 支持录制通关步骤，放慢游戏速度，加载内置的过关步骤。
- **扩展功能**：除了原版地图元素，引擎提供接口支持提交新的机关。
- **开发工具**：可以将编辑器创作的新地图打包回jar包通过模拟器验证。

更完整的产品设计、架构、格式与机制说明见 [`docs/`](docs/README.md)。
