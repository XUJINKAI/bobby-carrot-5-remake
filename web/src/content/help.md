## 游戏

- **WASD / 方向键**：控制移动
- **Tab**：录制面板（自由探索）
- **~**：Debug 模式（自由探索）
    - Debug 模式下双击地图瞬移 Bobby

## 通用

- **Ctrl+Z**：撤销
- **Ctrl+Y**：重做
- **滚轮 / +/- / 双指捏合**：缩放地图与平移地图

## Editor

- **Tab**：切换 Palette / Surface
- **1**：选择
- **2**：画笔
- **3**：Surface 智能填充
- **4**：Palette 删除工具
- **Ctrl+A**：全选地图
- **Ctrl+C / X / V**：复制 / 剪切 / 粘贴
- **Delete / Backspace**：删除选中的 Entity
- **Q / E**：切换 Palette Entity 形态
- **右键**：切换选择工具并选择当前格
