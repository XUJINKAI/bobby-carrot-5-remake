## 游戏

- **滑动屏幕/方向键/WASD**: 控制移动
- **滚轮 / +/- / 双指捏合**：缩放地图与平移地图
- **Z**：切换录制面板
- **X**：切换屏幕摇杆
- **[ / ]**：上一关／下一关
- **Shift+R**：重新开始
- **Ctrl+Z**：撤销
- **Ctrl+Y**：重做
- **~**：Debug 模式
  - Debug 模式下双击地图瞬移 Bobby

## 页面
- **方向键**: 选择
- **enter**: 确认
- **Escape**: 返回上一个页面
- **Tab / Shift+Tab**：切换合集
- **P**：继续游玩
- **Shift+S**：随机关卡
- **M**：音乐开关
- **?**：帮助

## 编辑器

- **1**：选择
- **2**：画笔
- **3**：Surface 智能填充
- **4**：Palette 删除工具
- **Z**：切换 Palette / Surface
- **X**：切换 Inspector / Level
- **Ctrl+Z**：撤销
- **Ctrl+Y**：重做
- **Ctrl+A**：全选地图
- **Ctrl+C / X / V**：复制 / 剪切 / 粘贴
- **Delete / Backspace**：删除选中的 Entity
- **Q / E**：切换 Palette Entity 形态
- **右键**：切换选择工具并选择当前格
