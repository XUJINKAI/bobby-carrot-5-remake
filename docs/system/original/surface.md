# 静态地形说明

本文档是对assets.md的补充说明，列举`ts.png`中的静态地形。

本文档用于说明 Editor 中 Surface 的分类。可执行的 atlas 名称与坐标归类以
`model/src/map/entity/ts-visuals.json` 为单一可信源。

坐标遵从README规则，row,column 皆为从1开始。此外，坐标还会有 1,9--3,10 这样的表示法，意思是以这两个坐标画矩阵覆盖的所有图。

Editor 中每个 Surface atlas 单元都作为一个单格 Entity 持久化。多个单元可以在视觉上拼成完整图案，但不形成 multi-cell Object；同一家族通过 semantic type 与 `variant: ts-<row>-<column>` 区分图块。
