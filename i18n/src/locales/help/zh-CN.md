## 页面与焦点

- **↑↓**：选择首页模式及内嵌链接；**Enter**：打开所选入口
- 首页 **Tab**：模式菜单与 Demo 之间循环切换
- **方向键**：选择关卡列表中的条目
- Explore **Tab / Shift+Tab**：切换下一个／上一个 Collection；**↑↓←→** 选关
- Explore **Shift+S**：随机关卡；**P**：继续游玩
- **Tab / Shift+Tab**：按页面配置向前／向后移动焦点
- **Esc**：关闭当前弹窗或返回上一级页面
- **[ / ]**：自由探索中切换上一关／下一关
- 结算面板 **←→**：选择按钮；**Enter**：确认，默认下一关或重试
- **Esc**：结算面板返回列表，Editor Play Test 返回编辑

## 游戏

- **滑动屏幕/方向键/WASD**: 控制移动
- **Z**：切换录制面板（自由探索）
- **X**：切换屏幕摇杆
- **Shift+R**：重新开始
- **~**：Debug 模式（自由探索）
  - Debug 模式下双击地图瞬移 Bobby

## 通用

- **M**：音乐开关
- **?**：帮助
- **Ctrl+Z**：撤销
- **Ctrl+Y**：重做
- **滚轮 / +/- / 双指捏合**：缩放地图与平移地图

## Editor

- **Z**：切换 Palette / Surface
- **X**：切换 Inspector / Level
- **1**：选择
- **2**：画笔
- **3**：Surface 智能填充
- **4**：Palette 删除工具
- **Ctrl+A**：全选地图
- **Ctrl+C / X / V**：复制 / 剪切 / 粘贴
- **Delete / Backspace**：删除选中的 Entity
- **Q / E**：切换 Palette Entity 形态
- **右键**：切换选择工具并选择当前格
